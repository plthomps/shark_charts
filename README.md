# Shark Presence Dashboard — GitHub split-ZIP edition

Upload `app.py`, `requirements.txt`, and the `results/` directory (containing 15 per-year ZIP archives) to **one GitHub repository**. Deploy `app.py` on Streamlit Community Cloud. The app reads individual ZIPs directly without extracting them.

Each ZIP is about 5–6 MB. The original FORWARD.zip and LOYO.zip are not used in this edition.

The app reads original internal archive paths like `FORWARD/2018_ALL/roc.png` and `LOYO/2024_NIGHT/pdp_1way.png`.
